# Azurecord V52 Beta 8.2 — Social Controls

## Novidades

- AzurePoints sincronizado no D1 Cloud.
- Preview de perfil compacto ao clicar no nome/avatar no chat.
- Botão **Exibir perfil completo**.
- Perfil completo responsivo em janelas pequenas e médias.
- Mensagem direta fecha o modal e abre a DM.
- Adicionar/remover amigo.
- Bloquear/desbloquear. Bloquear remove a amizade; desbloquear não restaura a amizade.
- Ignorar/parar de ignorar. Ignorar mantém a amizade, mas oculta as mensagens daquele usuário.
- Worker 0.7 com `azurePointsCloud` e `userControls`.

## Ainda não entra nesta build

- Armazenamento grande de arquivos: será migrado para R2 antes de remover o limite atual.
- Chamadas de voz/vídeo/tela: planejadas para uma versão futura com WebRTC.
