# Publicar Azurecord Web no GitHub Pages

O pacote já inclui `docs/index.html` e todos os arquivos estáticos necessários.

1. Copie a pasta `docs` para a raiz do repositório `azurecord-web`.
2. Faça commit e push para `main`.
3. No GitHub abra o repositório.
4. Entre em **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Branch: **main**.
7. Folder: **/docs**.
8. Clique em **Save**.

O endereço padrão será:
`https://SEU-USUARIO.github.io/azurecord-web/`

O Azurecord Web continua usando:
`https://azurecord-api.giovannisilvaalves604.workers.dev`

Não coloque tokens, senhas ou segredos dentro da pasta `docs`.
