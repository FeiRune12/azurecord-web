# Recuperação de conta Azure — Beta 8.3

Contas Cloud usam o Worker + D1. Para recuperar uma conta em outro PC ou no navegador, abra o Azurecord e entre com o mesmo email/username e senha.

Os antigos procedimentos de restaurar `azurecord.json`, `.bak` ou um backend Node local eram necessários em betas antigas e **não são o fluxo normal da Beta 8.3**.

Dados que já estão no Cloud, como identidade da conta, perfil, amizades, DMs Cloud, servidores, AzurePoints e histórico Cloud da Lola, voltam após o login e carregamento da API.

Preferências puramente locais podem continuar específicas de cada dispositivo.
